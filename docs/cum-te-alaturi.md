# Cum te alături

## Cerințe

* Un PC care rulează **GTA V** (versiunea originală, Steam / Epic / Rockstar Launcher)
* Clientul **FiveM** instalat de pe [fivem.net](https://fivem.net)
* Cont de **Discord**
* Microfon funcțional

## Pași pentru conectare

1. Instalează și deschide **FiveM**.
2. Caută „NewLife” în lista de servere sau apasă **F8** și scrie `connect` urmat de adresa serverului.
3. Intră pe **Discord-ul** nostru și citește canalul `#reguli`.
4. Creează-ți personajul și începe aventura!

## Probleme la conectare?

| Problemă                         | Soluție                                            |
| -------------------------------- | -------------------------------------------------- |
| Eroare la descărcarea resurselor | Șterge folderul `cache` din directorul FiveM       |
| „Server is full”                 | Încearcă din nou peste câteva minute               |
| Nu merge microfonul              | Verifică setările de voce din FiveM și din Windows |

Dacă problema continuă, deschide un ticket pe Discord, în `#suport`.
