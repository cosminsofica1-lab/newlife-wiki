# Bine ai venit pe NewLife 🌆

**NewLife** este un server de FiveM cu roleplay, unde poți începe o viață nouă în Los Santos. Fie că vrei să fii polițist, medic, mecanic, om de afaceri sau șeful unui gang, povestea ta o scrii tu.

## De ce NewLife?

* 🎭 Roleplay într-o comunitate prietenoasă
* 💼 Joburi și facțiuni variate
* 💰 Economie echilibrată, construită pentru progres real
* 🛠️ Staff activ și update-uri constante
* 🇷🇴 Comunitate românească
