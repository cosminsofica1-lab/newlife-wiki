# Regulament Roleplay

## 1. Roleplay ( RP )

**Roleplay-ul** înseamnă să interpretezi un personaj fictiv care trăiește o poveste coerentă în Los Santos. Tot ce faci în joc trebuie să aibă sens pentru personajul tău, nu pentru tine ca jucător.

## 2. In Character ( IC ) și Out Of Character ( OOC )

**IC** înseamnă tot ce se petrece în joc, din perspectiva personajului. **OOC** înseamnă tot ce ține de tine ca persoană reală: Discord, chat-ul din afara rolului, informații aflate din alte surse.

{% hint style="info" %}
Din momentul conectării și până la deconectare rămâi în IC. Excepție face doar discuția cu un membru staff, într-un ticket.
{% endhint %}

## 3. Metagaming ( MG )

**Metagaming-ul** înseamnă folosirea în joc a informațiilor obținute din afara jocului (Discord, stream-uri, recunoașterea unei persoane după vocea reală etc.).

{% hint style="danger" %}
Folosirea informațiilor OOC în IC se sancționează conform regulamentului.
{% endhint %}

## 4. Powergaming ( PG )

**Powergaming-ul** înseamnă acțiuni nerealiste sau forțarea unui jucător într-o situație în care nu are nicio șansă să reacționeze.

{% hint style="info" %}
**Exemple**

* Rolezi acțiuni asupra altui jucător fără să-i lași timp să răspundă.
* Faci un accident grav și pleci fără să rolezi.
* Vorbești în timp ce ești în comă.
{% endhint %}

## 5. Random Deathmatch ( RDM )

**RDM** înseamnă să rănești sau să omori un jucător fără niciun motiv roleplay întemeiat.

## 6. Vehicle Deathmatch ( VDM )

**VDM** înseamnă să lovești sau să omori jucători cu un vehicul, fără motiv roleplay și fără ca situația să o justifice.

## 7. Non Fear Roleplay ( NFR )

**NFR** înseamnă să nu simulezi frica atunci când ești amenințat cu o armă sau când te afli într-un pericol real.

{% hint style="info" %}
**Exemple**

* Ești amenințat cu arma și reacționezi agresiv sau râzi de agresor.
* Te plimbi nepăsător într-o zonă unde se trage.
{% endhint %}

## 8. Character Kill ( CK ) și Player Kill ( PK )

**CK** înseamnă pierderea definitivă a personajului, cu resetarea bunurilor și a poveștii. **PK** înseamnă că, după ce ai primit respawn, personajul uită tot ce s-a întâmplat înainte de moarte.

## 9. Revenge Kill ( RK )

**RK** înseamnă să te răzbuni imediat pe cel care te-a omorât, după respawn. După un PK nu ai voie să revii în zonă și să te implici în același conflict.

## 10. Întrerupere de roleplay

Este interzis să părăsești sau să oprești o acțiune de roleplay aflată în desfășurare (disconnect, ticket în timpul acțiunii, refuzul de a rola). Orice neînțelegere se rezolvă **după** terminarea acțiunii, printr-un ticket.

{% hint style="warning" %}
Acest regulament este un punct de plecare. Completează-l cu regulile specifice serverului tău (sancțiuni, facțiuni, zone etc.).
{% endhint %}
