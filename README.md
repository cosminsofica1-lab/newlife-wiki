### 🎯 Despre Serverul NewLife
Comunitatea **NewLife** oferă o experiență de **Medium-Hard Roleplay (75-80%)**, centrată pe realism, dezvoltarea caracterelor și o economie dinamică și echilibrată. Ne asigurăm că fiecare jucător are posibilitatea de a-și crea propria poveste, fie ca membru al forțelor de ordine, medic salvator, mecanic dedicat sau conducător al unei grupări de crimă organizată.
{% endhint %}

## ⚡ Conectare Rapidă pe Server

Puteți să vă alăturați serverului **NewLife Roleplay** prin oricare dintre următoarele metode:

{% hint style="success" %}
**Metoda 1: Consola FiveM (Recomandat)**
1. Deschide clientul **FiveM**.
2. Apasă tasta **`F8`** pentru a deschide consola internă.
3. Introdu comanda:
   ```bash
   connect fivem.newlife-rp.ro
   ```
4. Apasă `ENTER` și așteaptă încărcarea resurselor.
{% endhint %}

{% hint style="info" %}
**Metoda 2: Căutare în Server List**
* În meniul principal FiveM, navighează la **Play / Joacă**.
* La bara de căutare scrie: `NewLife Romania` sau `NewLife Roleplay`.
* Selectează serverul oficial și apasă **Connect**.
{% endhint %}

{% hint style="warning" %}
**Important:** Înainte de a te conecta, asigură-te că ești membru pe serverul nostru de Discord: [discord.gg/newliferp](https://discord.gg/newliferp) și că ai contul de Steam/Discord legat de FiveM.
{% endhint %}

## 🛡️ Principiile Comunității NewLife

1. **Respect Reciproc**: Comportamentul toxic, discriminarea, jignirile OOC sau insultele pe chat-ul global / Discord sunt strict interzise.
2. **Prioritate Poveștii (No-Win Mentality)**: Roleplay-ul nu înseamnă să câștigi fiecare schimb de focuri sau urmărire, ci să oferi o scenă credibilă și distractivă pentru toți cei implicați.
3. **Rolul Staff-ului**: Echipa administrativă este mereu disponibilă pe Discord și prin sistemul de ticket (`/report`) pentru a menține un gameplay curat și civilizat.

{% hint style="info" %}
*Pentru orice nelămurire suplimentară, deschide un ticket pe canalul oficial de Discord la secțiunea `#suport-jucatori`.*
{% endhint %}
